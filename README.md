## 🧠 Engineering Philosophy

```text
Architecture → Code → Ship → Measure → Iterate
```

- **Design for failure:** systems should remain useful when connectivity, APIs, or assumptions fail.
- **Build for the edge:** offline-first software exposes the constraints that make products genuinely resilient.
- **Use AI deliberately:** Claude for cloud reasoning; Ollama for local and edge inference.
- **Optimize for reality:** latency, maintainability, deployment, and user value matter more than hype.
- **Ship with feedback:** production usage is the fastest path from an interesting idea to a valuable product.

### What I Actually Do

- Design systems that survive unreliable connectivity
- Build custom algorithms, recommendation engines, and ML scoring pipelines
- Automate workflows across web platforms and business operations
- Develop multi-tenant SaaS products and real-time data systems
- Turn product ideas into maintained, revenue-generating software
